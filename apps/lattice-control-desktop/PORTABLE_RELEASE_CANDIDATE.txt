LATTICE CONTROL - WINDOWS PORTABLE RELEASE CANDIDATE

This is a local portable release-candidate package. It is not installed or
released, and it does not register a service or change global configuration.

Launch: double-click LATTICE.exe

With no command-line override, the desktop probes http://127.0.0.1:4317/ and
reuses Control only when its bundled runtime identity matches exactly. If no
listener exists, it starts the bundled Node.js + Control runtime. A foreign or
incompatible listener fails closed. Closing LATTICE stops only the Control
process it started; a reused Control is never stopped by the desktop.

Control stores its existing local SQLite data under:
%LOCALAPPDATA%\LATTICE\control\lattice-control.db

WebView2 user data is stored outside this package under:
%LOCALAPPDATA%\LATTICE\ControlDesktop\WebView2

The Microsoft Edge WebView2 Runtime must be present on Windows. The package
contains the self-contained .NET runtime needed by this candidate.
