# LATTICE DevOS v0.1.0-alpha.1

This is a Windows x86_64 developer preview of the simplified, modular LATTICE
baseline. It is a checkpoint that can be installed, inspected, and tested. It
is not the completed autonomous-development product.

## What works

- `lattice.exe version` reports the exact package version.
- `lattice.exe status` shows every retained component and whether it is core,
  optional, deferred, or retired.
- `lattice.exe status --json` provides the same read-only information as stable
  JSON for scripts.
- The default Rust core and repository verification suites are independently
  runnable from source.

## What is not included

- no task creation, dispatch, completion, or resume command;
- no PostgreSQL installer or live database startup;
- no Codex agent-loop replacement;
- no OpenClaw or mandatory full-chain startup;
- no Hermes startup;
- no Graphify or Codebase Memory executable in this package;
- no deployment, self-update, or release automation.

Those limits are intentional. This preview proves the new product boundary and
provides a reproducible baseline without presenting historical research code as
a finished user workflow.

## Run

Extract the ZIP and run:

```powershell
.\lattice.exe version
.\lattice.exe status
.\lattice.exe status --json
```

The commands perform no network, database, process-control, Git, or file-write
operation.

## Build from source

Requirements: Windows x86_64, Rust 1.97 or newer, and Node.js 24.15 or newer.

```powershell
npm.cmd run verify
npm.cmd run test:core
npm.cmd run alpha:package
```

The package command builds the release binary, executes version and JSON smoke
checks, creates a ZIP under `dist`, and writes a SHA-256 checksum next to it.

## Release meaning

This package may be shared privately for evaluation after its source commit is
pushed and reviewed. A public GitHub release, default-branch merge, license
choice, deployment, and claim of production readiness remain separate actions.
